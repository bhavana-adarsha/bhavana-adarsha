## Featured Projects
 
### Clinical Lab Summarizer (RAG)
A GPT-4 RAG application that turns raw lab results into structured, plain-language patient summaries grounded in a medical knowledge base. Validated with 15 clinicians and 50 patients.
- **Stack:** GPT-4, RAG, FHIR, Python, React
- **Product-layer guardrails:** hedging enforcement, no-diagnostic-claims, knowledge-base grounding
- **PM focus:** defined the evaluation criteria and safety constraints that gate a release, not just the build
### Workforce Anomaly Explainer Agent (ReAct)
An agent that analyzes scheduling and payroll data, detects anomalies with deterministic Python logic, and explains each one in plain language for non-technical managers. Built so a workforce manager can act immediately without a data analyst.
- **Stack:** React + Vite, Flask, LangChain + GPT-4, Python 3
- **Pattern:** deterministic detection paired with LLM explanation across 6 anomaly types
### Payroll and Employee Onboarding Agent
A conversational agent that automates multi-step employee onboarding data collection and form completion so HR teams can focus on people, not paperwork.
- **Stack:** React, Vite, Python, Flask, LangChain, GPT-4
- **Pattern:** multi-step conversational data collection with GPT-4 input validation, full-stack AI product architecture
### AI Release Readiness Framework
A product-layer framework for taking a clinical AI copilot from Alpha to GA: evaluation criteria, exit gates, guardrail design, human-in-the-loop patterns, safety metrics, pilot design, and a governance sign-off checklist.
 
### AI Agent GTM Playbook
A go-to-market playbook for taking an AI agent from working prototype to adopted tool. Treats adoption as a first-class outcome alongside accuracy and reliability, covering pilot design, champion identification, three-phase rollout, and leading and lagging adoption metrics. Building the agent is the easy part; getting people to keep using it is the hard part, and this addresses that directly.
 
### Patient Journey: Test Order to Claims Resolution
End-to-end mapping of the journey a patient experiences from the initial clinical encounter through insurance adjudication and final billing, surfacing the friction points that represent opportunities for operational improvement and AI-assisted intervention.
 
### Modern Data Stack: Applied Concepts and Tooling Fluency
Hands-on engagement with modern data stack tooling in the context of AI product development, specifically how data infrastructure decisions shape LLM product quality, reliability, and observability.
